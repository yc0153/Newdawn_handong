# 개발 결정과 운영 확정 항목

## 사용자가 확정한 기술

- Next.js 프론트엔드.
- Supabase 백엔드.

## 원문에서 확정된 제품 요구

공개 지도 먼저 진입, 독립 작성 주소, 위치 클릭 즉시 작성, 이름·연락처 등 미수집, 이용자 계정 없음, 약 200m 격자 대표점만 저장, 공개 선택 기본 꺼짐, 지도 선택이 플레이어 선택의 선행 조건, 담당자 수동 요약 250자 이하, 검토 대기·공개·숨김 및 별도 삭제, 공개 요약 수정 전 숨김, 담당자별 계정·동일 역할, 최소 이력, 멱등 등록·빈도 제한, 한·영 UI, 공개 최소 필드, 30초 재조회·60초 내 철회, 플레이어 초기 정지·12초 순환·수동 이동 후 정지. 자세한 근거는 SOURCE_MAP.md를 따른다.

## 개발을 시작하기 위한 제안 기본값

다음은 원문 요구를 구현 가능하게 구체화한 선택이며, 학교의 확정 사실이 아니다.

| 항목 | 개발 기본값 | 변경 영향 |
| --- | --- | --- |
| 프레임워크 | Next.js 16.3.8 App Router, React 19.3.0, TypeScript 5.9.3 | lockfile·Auth proxy·빌드 검수 |
| 서버 경계 | Next Route Handlers가 Supabase RPC를 호출 | BFF 권한·키 노출 검수 |
| 지도 | Leaflet 기반 공급자 어댑터 구조. 공급자는 미정 | 타일 URL·API키·저작권·사용량·약관 |
| 경로 | /map, /submit, /player, /admin 및 시연 query alias | 학교에 제공할 링크 |
| 담당자 인증 | 사전 발급 이메일·비밀번호, 공개 가입·익명 Auth 없음 | 학교 계정 운영·비밀번호 재설정 |
| 위치 격자 | 고정 기준점의 약 200m 지역 평면 격자 `pohang-v1` | 이후 변경 시 기존 cell의 의미 유지 |
| 격자 기준 | 원점 36.0°N/129.3°E, 기준 위도 36.04°, R=6371008.8m | 기술 좌표계 기본값이며 수집 지역 가정 아님 |
| 허용 지역 | 서버의 allowed_cells 목록. 초기 목록은 비어 있음 | 학교가 선택한 영역을 격자로 확정·등록 |
| 등록 빈도 | 10분 5건, 하루 20건/일일 HMAC IP 키 | 공유망 영향·운영 수치 확인 후 조정 |
| 요청 크기 | JSON 최대 8KB, 요청 timeout 10초 | 과도한 입력·네트워크 실패 검수 |
| 삭제 | deleted_at 기록 후 원문·요약 비우기, 영수증·최소 이력 유지 | 보유·파기 기준에 맞춘 후속 정리 |
| 글자 수 | NFC 후 Unicode codepoint; 최소에서 Unicode 공백 제외 | 웹·서버·DB 같은 규칙 검증 |
| 재생 순서 | 내부 created_at 오름차순, 내부 id로 동률 정렬 | 공개 응답에 등록일을 추가하지 않음 |
| 전체 공개 데이터 | 첫 버전은 전체 snapshot, 상한 5000건 초과 시 명시 오류 | 학교 규모 확정 시 페이지·신선도 설계 재검토 |
| 성능 목표 | 검수용 공개 5000건·관리자 100건/페이지에서 측정 | 확정 사용자 수·동시접속 수를 의미하지 않음 |
| 민감 응답 | no-store, 원문 로그·분석 금지 | 호스팅 로그·관측 도구 설정 |

## 구현 중 추가·변경한 결정 (2026-10-11)

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 담당자 변경 경로 | `admin_opinion_action` RPC만 허용. 테이블 직접 UPDATE 권한 회수, RPC는 SECURITY DEFINER로 바꾸고 함수·트리거에서 활성 담당자를 다시 검사 | 직접 UPDATE로 버전 충돌 검사·이력·숨김 규칙을 우회할 수 있었음(독립 검토에서 발견) |
| 숨김과 상영 | 숨기면 상영 포함도 해제. 요약을 고쳐 다시 공개해도 상영은 담당자가 다시 켜야 함 | 고친 요약이 확인 없이 간담회 화면에 나가지 않도록 |
| 공개 안내 버전 | 서버는 형식만 검사하고 DB `service_settings.notice_version`과 비교 | 코드와 DB 이중 정의 시 등록이 막히는 문제 방지 |
| 신뢰 IP 헤더 | 지정한 헤더 하나만 읽고, 목록 형태면 플랫폼이 붙인 마지막 값을 사용. 개발 서버에서 비어 있으면 모든 요청이 한 버킷을 공유 | 임의 XFF 첫 값을 믿지 않기 위해 |
| 지도 공급자 미정 | 개발 서버에서만 OSM 개발용 타일(화면 표시), 운영 빌드는 설정 없으면 지도 대신 안내 | 공급자 확정 전 운영 타일 사용 금지 |
| 같은 격자 여러 의견 | 핀 하나에 건수 표시, 핀을 누르면 그 위치 의견 목록으로 좁혀 각각 선택 | 대표 의견 하나만 남기지 않기 위해 |
| 공개 목록 렌더링 | 100건씩 ‘더 보기’ | 5000건에서 분야 전환 4.6초 → 0.1초 |
| 언어 선택 저장 | 화면 언어(ko/en)만 브라우저 저장소에 저장. 작성 내용·위치는 저장하지 않음 | 원좌표·초안 비저장 원칙 |
| iframe | 공개 화면은 `frame-ancestors 'self'` + `ALLOWED_FRAME_ANCESTORS`, 관리자 화면은 삽입 금지 | 학교 연결 방식 확정 전 안전한 기본값 |
| GPS 등 | `Permissions-Policy`로 위치·카메라·마이크 차단 | 범위 제외 기능 |
| 디자인 기준 (10-13) | lip.center의 실제 계산된 스타일을 측정해 `DESIGN.md`로 정리하고 `globals.css` 토큰으로 적용. 로고·이미지·상용 폰트는 가져오지 않음. 보조 글자·입력 테두리는 대비 기준에 맞게 한 단계 진하게 | 학교 사이트와 같은 인상 + 접근성 기준 유지 |
| 상영 흐름 안내 (10-13) | 공개만 하고 상영에 넣지 않은 의견은 목록에 ‘상영 대기’, 상세 상단에 ‘플레이어에도 상영’ 안내. 상영 의견이 1건이면 플레이어 하단에 ‘2건 이상이면 자동 재생’ 표시. 상영 포함은 여전히 담당자가 직접 누름 | 테스트 중 “의견을 남겼는데 플레이어에서 재생이 안 된다”는 피드백. 원인은 공개·상영 포함 단계와 2건 이상 재생 규칙이었음 |
| 의견 등록 영역 (10-15) | 테스트 배포의 허용 영역을 포항시 전체(남구+북구 행정구역, 통계청 2013 경계)로 확대. 경계에 걸친 약 200m 칸까지 포함해 29,264칸. 적용 SQL은 `supabase/dev/pohang_whole_city.sql`. 지도에는 칸마다 테두리를 그리지 않고 채움 1개 + 실제 경계선 1개로 그림 | 팀 요청. 실제 수집 지역은 학교와 확정 전이므로 운영 전 다시 정함 |
| 주소 목록·로드뷰 (10-15) | 팀 요청으로 PRD의 '주소 검색 제외'를 바꿈. 카카오 키가 있으면 지도 클릭 → 주변 상세주소(도로명·지번·우편번호)·검색 → 카카오 로드뷰 가운데 핀 → 의견 작성. **저장·공개는 그대로 약 200m 칸 번호만**(주소·로드뷰 방향·좌표는 서버로 보내지 않음). 바탕 지도도 카카오로 바꾸고, SDK를 못 불러오면 타일 지도와 기존 흐름으로 대체 | 위치를 찾기 쉽게 하면서 개인 위치 보호 원칙 유지. 단, 누른 좌표와 검색어는 브라우저에서 카카오로 직접 전송됨(카카오 지도 이용 조건). 학교 안내문에 반영 필요 |

## 운영 전에 학교와 확정할 항목

| 항목 | 필요한 결정 | 로컬 개발 가능 여부 |
| --- | --- | --- |
| 실제 수집 지역 | 양덕동은 시안 가정. 실제 구역과 경계 격자 승인 | 가능. 테스트 셀을 실제 지역으로 표시하지 않음 |
| 지도 공급자 | 한국어·영어 가독성, 출처, 타일·SDK 라이선스와 비용 | 어댑터 개발 가능. 공급자 확정 전 운영 타일 사용 보류 |
| 학교 연결 | 링크 또는 iframe, 도메인, CSP frame-ancestors | 독립 링크 기반 개발 가능 |
| 운영 담당자 | 개인별 계정 발급 대상과 검토·삭제 책임자 | 로컬 테스트 계정으로 검수 가능 |
| 공개 안내와 개인정보 | 수집 목적, 원문 접근자, 보유·파기 기간, 문의 채널 | 데이터 처리 구현 가능. 실제 수집 시작 전 확정 |
| 배포 환경 | Next 서버 호스트, Supabase 프로젝트·리전·키, TLS | 로컬 실행 가능. 실환경 연결은 별도 |
| 규모와 예산 | 총 데이터, 피크 요청, 동시접속, 지도 사용량 | 기본 테스트 가능. 운영 SLA·월 비용은 미확정 |
| LIP 자산 | 정확한 색상·폰트·로고 파일과 사용 범위 | 근사 청색·시스템 폰트로 개발 가능 |

현재 생성된 클라우드 프로젝트·공식 배포 주소·운영 승인 지역은 없다. 확정되면 이 표를 날짜와 결정 근거와 함께 수정한다. 운영 등록을 여는 설정은 기본 false를 유지한다.
